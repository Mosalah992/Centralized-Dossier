# Ayleid archive chrome

The archive-wide interface frame uses the Ayleid glyph row documented by [UESP’s *Elven
Alphabets* reference](https://en.uesp.net/wiki/Lore:Elven_Alphabets). The local
glyph copies in `public/runes/ayleid/` are the specific source images for the
letters in the ornament, not a downloaded font or a runtime third-party call.

The horizontal band reads **THALMOR · EMBASSY** when transliterated. It and its
vertical rail are decorative gold-and-green chrome around the full archive
interface, not functional text: all reader-facing labels remain in the archive’s
existing accessible Latin typography. The geometry follows Arcanaeum’s terminal
frame placement, but omits its blue palette, dragon, animal, and ecclesiastical
imagery so the Thalmor archive keeps its own Dominion tone. On small screens the
side rails are omitted, leaving the top and bottom bands room to breathe.

Source glyphs: A, B, E, H, L, M, O, R, S, T, and Y from the Ayleid row. The UESP
page was consulted on 2026-09-29. If the glyph set is replaced, update this note
and retain a self-hosted asset path; the site’s CSP and privacy posture prohibit
remote image dependencies.
