# Ayleid ornament band

The shared page border uses the Ayleid glyph row documented by [UESP’s *Elven
Alphabets* reference](https://en.uesp.net/wiki/Lore:Elven_Alphabets). The local
glyph copies in `public/runes/ayleid/` are the specific source images for the
letters in the ornament, not a downloaded font or a runtime third-party call.

The band reads **THALMOR · EMBASSY** when transliterated. It is decorative
goldwork, not functional text: all reader-facing labels remain in the archive’s
existing accessible Latin typography. The surrounding geometry follows the
placement of Arcanaeum’s former illuminated-manuscript treatment, but omits its
dragon, animal, and ecclesiastical imagery so the Thalmor archive keeps its own
Dominion palette and tone.

Source glyphs: A, B, E, H, L, M, O, R, S, T, and Y from the Ayleid row. The UESP
page was consulted on 2026-09-29. If the glyph set is replaced, update this note
and retain a self-hosted asset path; the site’s CSP and privacy posture prohibit
remote image dependencies.
